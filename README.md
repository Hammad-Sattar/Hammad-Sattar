### 👋 About Me

I'm a Software Engineer based in Islamabad, Pakistan, currently working remotely for **CodeCube (USA)**.

On the backend, I build REST APIs with **C#, .NET Core, EF Core and SQL Server**. On the cloud side, I work with **Azure App Service, VM Scale Sets, Load Balancer and VNets**. For DevOps, I use **Terraform, GitHub Actions and Azure DevOps** to automate infrastructure and deployments.

My rule of thumb: if I've deployed something twice by hand, the third time it becomes a pipeline.
